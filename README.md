# 58 Full-Stack Web Development Projects

This repository contains 58 full-stack web development projects built as part of my software development practice and experiments.

Each project is a separate web application with its own frontend and backend.

All 58 projects are deployed on Vercel and can be opened from the main showcase website.

## Main Showcase

You can browse all 58 projects from one place:

https://master-58-full-stack-showcase.vercel.app

From the showcase you can search for a project and open its live version.

## What I Worked With

Most of the projects use:

- Node.js
- Express.js
- JavaScript
- HTML
- CSS
- REST APIs
- JSON based data storage
- Vercel
- Git and GitHub

The projects include common full-stack features such as:

- CRUD operations
- Search
- Filtering
- Forms
- API requests
- Dashboard pages
- Tables
- Notifications
- Responsive layouts
- Data management

The backend generally uses Express and provides REST API endpoints for the frontend.

The frontend is built with HTML CSS and JavaScript with Tailwind CSS used in the project setup. :contentReference[oaicite:1]{index=1}

## How the Projects Are Structured

Each project is kept separate so it can be developed and tested on its own.

A typical project looks like this:

```text
project/
│
├── server.js
├── api/
│   └── index.js
│
├── public/
│   └── index.html
│
├── data/
│   └── db.json
│
├── package.json
└── test.js
