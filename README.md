## 🏛️ Architecture & Engineering Standards

Every project in this repository has been crafted as a complete, independent, production-grade full-stack web application following industry standards:

1. **Backend REST API (`server.js`):**
   - Built with **Node.js** and **Express.js**.
   - Implements full CRUD operations (`GET`, `POST`, `PUT`, `DELETE`).
   - Query filters (multi-keyword search, category filtering, status filters).
   - `/api/health` system diagnostics and author attribution endpoints.
   - `/api/stats` live KPI metrics calculation.
   - Secondary domain entity endpoints for interconnected workflows.

2. **Persistent Storage Layer (`data/db.json`):**
   - File-backed persistent JSON database supporting atomic transactional reads and writes per project.
   - Pre-loaded with comprehensive, authentic domain records.

3. **Frontend UI/UX (`public/index.html`):**
   - Human-designed, senior-developer quality interface with modern typography (**Inter**), semantic HTML5, and **Tailwind CSS**.
   - FontAwesome 6 icon set for crisp visual cues.
   - Interactive data tables with status badges, localized currency formatting, and responsive grid layouts.
   - Debounced search bar for instant client-side query filtering.
   - Modal-driven CRUD forms with client-side form validation.
   - Toast notification feedback system for seamless user experience.
   - Prominent student identification badge: **"Done By SaiVatsal 2500040224"** on all navigation headers, footers, and modal windows.

4. **Automated Verification (`test.js` & `run-all-tests.js`):**
   - Standalone test suite in each project directory using ephemeral ports.
   - Master test runner verifying static assets, HTTP status codes, CRUD operations, and author attribution across all 58 projects.

## 🚀 Quickstart Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Any Specific Project
Navigate to any project directory and start its dedicated server:
```bash
cd 01-ecommerce-platform
node server.js
```
Open your browser at `http://localhost:3000`.

### 3. Run Automated Tests for a Single Project
```bash
cd 01-ecommerce-platform
node test.js
```

### 4. Run the Master Verification Test Suite (All 58 Projects)
```bash
node run-all-tests.js
```

### 5. Launch the Central Interactive Portal
Open `index.html` in your browser to search, browse, and access all 58 applications from one central dashboard.
